# Phase 5 功能报告 — 工厂总部 · 分店 · 渠道分销员

**版本:** 1.0  
**日期:** 2025-06-25  
**PRD:** `docs/prd/phase-5-distribution-and-allocation.md` v2.0

## 业务模型（已实现）

| 角色 | 能力 |
|------|------|
| **Admin 工厂总部** | 平台分销员 CRUD、拓店邀请码、分店审核绑定上级分销员、主数据 SKU、配货单、提现审批、平台资金总览、配送订单发货 |
| **渠道分销员** | 查看名下分店业绩、佣金明细、申请提现（总部审批） |
| **分店 Merchant** | 销售与订单、待核销自提、分店资金报表、向总部要货；**无**分销员管理 |
| **Store 商城** | 结账选自提/配送；自提展示核销码 |

## 核心规则

- 佣金：分店 `recruitedByDistributorId` → 订单 **FULFILLED** 时计提（自提核销 / 总部发货）
- 库存：`PAID` 不扣减；自提核销扣分店仓；配送发货扣 `MasterSku` 主仓并记 `DeliveryAllocationLedger`
- Merchant `POST /merchant/distributors` → **403**
